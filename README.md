# 🥔 Pringles 3D Experience

A cinematic, scroll-driven **3D Pringles web experience** built to explore immersive animations, smooth scrolling, and interactive product storytelling.

The experience features a perfectly curved chip, multiple flavors, and a 3D Pringles can that transforms and spins as you scroll through the page.

> **This is a fan-made concept build showcasing scroll-driven 3D animation with Next.js, GSAP, Framer Motion, and Lenis. All flavor descriptions are original text written for this demo.**
>
> Live Demo - https://pringles-two.vercel.app/

## ✨ Features

* Scroll-driven 3D product animations
* Smooth scrolling experience
* Interactive Pringles can transitions
* Animated flavor sections
* Cinematic product presentation
* Responsive design
* Modern motion-based UI
* Custom animations and transitions
* Immersive storytelling through scroll

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Abhishekkrvr/Pringles.git
```

Navigate into the project:

```bash
cd Pringles
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🎨 Animation Approach

The website combines multiple animation libraries for different parts of the experience:

**GSAP** handles complex scroll-driven animations and timelines.

**Framer Motion** is used for UI transitions and interactive motion.

**Lenis** provides smooth scrolling and helps create a more fluid relationship between scrolling and animations.

Together, these technologies create a cinematic, interactive product experience rather than a traditional static landing page.
